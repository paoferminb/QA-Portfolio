## 📋 Report Structure

Each report includes:

| Section | Description |
|---|---|
| **Sprint Summary** | Dates, scope, environment, and team |
| **Execution Metrics** | Total TCs, pass/fail/blocked counts and percentages |
| **Results by Area** | Breakdown per feature with visual indicators |
| **Bugs Found** | All defects logged during the sprint with severity |
| **Key Findings** | Patterns, risks, and observations beyond the numbers |
| **Release Recommendation** | GO / NO-GO with rationale |
